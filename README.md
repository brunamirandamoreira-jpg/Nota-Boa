# Nota Boa

Plataforma de materiais didáticos de Matemática.

## Painel administrativo
Cadastro e organização de materiais por ano escolar, conteúdo e tipo de arquivo.

## Funcionalidades planejadas
- Login de administradoras
- Envio de PDFs e slides
- Materiais gratuitos e pagos
- Preços em moedas
- Pacotes de materiais
- Armazenamento privado no Supabase
